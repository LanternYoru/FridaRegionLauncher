# v0.2.0-beta.1

这是 v0.2 的首个可运行测试版，保留 v0.1.1 的 DeviceRegion 和语言修复。子进程注入尚未实现，默认仍然只管理一个主进程。

## 使用

1. 在启动页配置 EXE 和环境。
2. 打开“程序配置”，输入名称并新增。可复制、重命名、搜索、删除或一键启动。
3. “编辑环境”切换到该配置；切换配置时先保存当前草稿。启动和“保存配置”也会保存活动配置。
4. 导出全部生成 JSON。导入仅加载数据，不会执行程序，且重新分配 ID，避免覆盖已有配置。上限 100 个配置、1 MB 文件。
5. 用户地区和 OOBE 地区是独立开关；日本兼容预设会同时启用两者。

## 区域与时区语义

- `GetUserGeoID(GEOCLASS_NATION)` 返回用户设置的 Windows GeoID，其他 class 保持原行为。
- `GetUserDefaultGeoName` 使用 Windows `GetGeoInfoW` 数据生成 ISO2 或 UN 数字名称，支持长度查询及短缓冲区错误。未知 GeoID 会导致初始化失败并清理尚未恢复的目标。
- `GetGeoInfoW/A` 与 `GetGeoInfoEx` 属于显式地区查询。传入模拟 GeoID/GeoName 时由 Windows 返回对应信息，启动器不会把调用者明确请求的其他国家替换为用户地区。
- 可选时区：Tokyo Standard Time、China Standard Time、Pacific Standard Time、W. Europe Standard Time、UTC。
- 读取 `EnumDynamicTimeZoneInformation` 与 `GetTimeZoneInformationForYear` 的 Windows 动态数据，覆盖时区信息、本地时间及默认时区的双向 SYSTEMTIME 转换。显式传入其他时区不变。
- `SystemTimeToTzSpecificLocalTimeEx` 和反向 Ex 转换使用日期对应的历史规则；非 Ex 使用当前规则，与 Windows API 参数语义保持一致。
- 旧 `FileTimeToLocalFileTime` / `LocalFileTimeToFileTime` 按当前偏移转换，不是任意历史日期转换。夏令时回拨时的重复本地时间遵循 Windows 的解析行为。
- 不改变 UTC 时钟或真实系统时区。规则准确度依赖本机 Windows 时区数据更新。

## 配置兼容

设置格式升级到 v2，读取 v1 自动迁移，保留原路径、参数、主题与最近程序。新增用户地区默认关闭，原时区开关保持原值。用户文件只有保存时才更新。

首次保存 v2 前自动保留 `settings.v1.backup.json`，不覆盖已有备份。旧版启动器不能读取 v2 设置；如需回退到 v0.1.1，可在退出启动器后用该备份恢复 settings.json。本版不会自动降级配置。
