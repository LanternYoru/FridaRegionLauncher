# v0.2.0-beta.2

## 云端构建与 UI 修复

上次云端失败不是打包器无法生成 EXE：日志显示 `pnpm test:backend` / `test:integration` 的 `.venv/Scripts/python.exe` 被 cmd 解析失败，探针未生成。多命令 PowerShell 步骤没有逐条检查退出码，最后成功的命令覆盖了前面的失败，随后 UI 测试等待不存在的探针退出而超时。证据上传还包含 Chromium 用户数据目录，触发 EBUSY。

- Python npm scripts 统一通过 Node `spawnSync` 调用绝对 EXE 路径，不经过 shell。
- 工作流逐条检查本机程序的退出码；任何测试失败立即停止该步骤。
- GUI 测试预先检查探针文件存在；便携版测试失败时也关闭 Electron 页面。
- 仅上传 JSON/PNG 测试证据，排除 Chromium 缓存与锁文件。
- 修复提交 `b966b7c` 的 [GitHub Actions #3](https://github.com/LanternYoru/FridaRegionLauncher/actions/runs/39735014676) 已实际全部通过，包括构建、验证与两个 artifact 上传。

用户地区卡片原本受 `.module-stack .card { flex: 1 }` 影响而等高分配，较多内容被压缩并裁掉。改为内容高度、禁止收缩，环境网格顶部对齐；在 940×680、1240×860 和 125% 缩放下检查卡片内容边界。

## 子进程 Hook

启动页提供独立开关，默认关闭，旧配置迁移不隐式开启。开启后：

- 对指定主进程启用 Frida child gating，仅处理其实际报告的子进程，递归覆盖孙进程。
- 复用启动时配置快照，不受运行期间编辑配置影响。
- attach、脚本加载、初始化确认完成后才 resume；加载成功仍不等于实际命中。
- 每个初始化进程使用独立 HANDLE 守护进程；后端退出或 25 秒超时终止正在初始化的目标。
- 注入失败、取消初始化或达到 32 个进程上限时，终止未成功注入的子进程并反馈原因，不默默放行。
- 主进程先退出时，继续监控已有子进程；整个进程组结束前不允许启动另一组。
- “终止全部进程”终止受监控主/子进程；“停止全部监控”和关闭 GUI 卸载已运行进程的 Hook，保留其运行。初始化中的进程会被终止。
- 后端回传各进程 PID、父 PID、角色、状态和 Hook 数；日志按实际调用进程记录 PID。

## 验证与边界

新增可复现探针 `tests/windows-integration/ChildProbe.cs` 和 `children.py`，验证第一条用户代码读取模拟值、子/孙进程配置继承、关闭开关、主进程提前退出、停止监控后的真实 API、整组终止、失败与上限清理及超时。

本机已通过上述原生子进程场景，包括主动取消初始化和真实等待 25 秒的守护超时；还通过 7 项前端、8 项后端测试，原有 DeviceRegion/.NET、语言/时区回归，以及实际 Electron 的配置管理、布局与整组控制测试。证据为 `artifacts/children-results.json` 和 `artifacts/ui-children.png`。

后续增加短命进程日志回归：保留同次运行在 Session 退出后送达的尾部日志，以启动代次隔离旧运行消息；限流时优先保留每个 API 的首次真实命中，防止大量 NLS 调用淹没首次注册表调用。增加两项测试后，前端共 8 项、后端共 9 项。

```powershell
pnpm build
pnpm test
pnpm test:backend
pnpm test:integration
.venv\Scripts\python.exe tests/windows-integration/children.py
node scripts/smoke-layout.mjs
node scripts/smoke-children.mjs
node scripts/smoke-children.mjs --packaged
```

子进程功能仍是测试功能：只支持 Windows x64；不覆盖未被 Frida child gating 捕获的服务、独立代理进程、原有实例和受保护进程。不以管理员提权或绕过保护扩大范围。配置模拟不是权限沙箱。

UI / 构建修复的云端成功记录与最终 beta.2 的 CI 是不同提交，应分别核对。第三方目标软件的完整业务地区判断与所有 Windows 版本尚未验证。

实现参考：[Frida 官方 child gating 示例](https://github.com/frida/frida-python/blob/main/examples/child_gating.py)。
